# Q-CalibNet

Do Parameterized Quantum Circuits Improve Calibration Under Domain Shift?
A Matched-Capacity Study on Chest X-Rays.

A frozen DenseNet-121 produces 1024-d ImageNet features, a linear bottleneck projects
them to 6 dimensions, and one of three heads produces a single logit:
a small MLP, a product PQC, or an entangling PQC. The two circuits differ only by a
CNOT ring, and the three heads are matched on trainable parameter count: 6,188 for each
PQC against 6,215 for the MLP. Heads are trained on CheXpert, temperature-scaled on
CheXpert validation, and then evaluated on VinDr-CXR without further fitting.

## Result in one paragraph

The PQC does **not** improve calibration over the capacity-matched MLP when the
CheXpert-fitted heads are transferred to VinDr-CXR. Temperature scaling lowers source
ECE and can raise target ECE on the same run. All 45 runs (5 tasks × 3 heads × 3 seeds)
are reported, including the 7 runs whose temperature fit degenerated. This is a
negative, controlled result: no quantum advantage, no hardware execution, no SOTA, and
no clinical claim is made.

## Datasets and private data

Datasets are not included in this repository. Obtain them from:

- CheXpert: https://www.kaggle.com/datasets/ashery/chexpert
- VinDr-CXR: https://physionet.org/content/vindr-cxr/1.0.0/

Extract them locally; do not upload dataset images or labels to GitHub. Expected layout:

```
MIDLquantumpersional/
├── CheXpert/{train.csv,valid.csv,train/,valid/}
├── VinBigData/{train.csv,train_meta.csv,train/,test/}
└── data/{splits/,features/,external/vindr_train.csv}
```

By default, the code looks for a sibling `MIDLquantumpersional` folder. For a different location, set `QCALIBNET_PRIVATE_ROOT`, or override individual paths in PowerShell:

```powershell
$env:QCALIBNET_PRIVATE_ROOT = 'E:\\private-data'
$env:QCALIBNET_CHEXPERT_DIR = 'E:\\private-data\\CheXpert'
$env:QCALIBNET_VINDR_DIR = 'E:\\private-data\\VinBigData'
$env:QCALIBNET_DATA_DIR = 'E:\\private-data\\data'
```

The frozen splits and feature cache belong under `QCALIBNET_DATA_DIR`; recreate them only when reproducing the experiment from scratch.

## Reproducing

```
python scripts/build_splits.py
python scripts/extract_features.py
python scripts/train.py --task no_finding --head mlp --seed 42
python scripts/summarize.py
python scripts/make_paper_artifacts.py
```

`python scripts/train.py --help` lists the task, head, and seed arguments.
The full grid is 5 tasks × 3 heads × 3 seeds. Figures are regenerated from frozen
splits and `results/tables/all_runs.csv`; the paper is never regenerated by retraining.
